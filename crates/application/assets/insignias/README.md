# Insignia symbols

Original vector artwork authored for Orbit Imperium, 2026-10-30, under the
repository's license. No external images, fonts, or generated raster assets.

- `compass.svg`: Wayfinder, four-point navigation star (free).
- `wings.svg`: Starwing, abstract winged star (free).
- `spire.svg`: Ascendant, ascending spire (free).

These trusted monochrome SVG masks use a 64 × 64 view box. The browser supplies
the authored foreground/background colors. The application includes only these free sources; the HTTP adapter publishes them through AssetStore at content-addressed keys. This trusted-originals namespace also retains immutable revisions across
rolling deployments. Arbitrary SVG uploads are not supported.

Additional operator content is installed through a separately published manifest,
never embedded here. See docs/operations/empire-customization.md. The legacy
Laureate original was removed from current community builds; its earlier public
license grant remains valid. Public tests use a distinct freely licensed circle.
