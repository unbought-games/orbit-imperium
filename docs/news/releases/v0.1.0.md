Orbit Imperium 0.1.0 is our first numbered open-source release.

The official server is already in open beta. This release gives people running
their own universe a specific version to install, inspect, and build on. The
source and container image belong to the same commit.

It's still early. There's more game to build, and plenty to improve. You can
follow the work, contribute a fix, or run an independent server. You don't need
an unbought games account to run a standalone universe.

## The game so far

Build a planetary economy, research technologies, and assemble fleets. Send them
on missions, read the reports, and decide what to do next. Construction, research,
and fleet events are handled by the server in a persistent universe.

This release includes the initial economy, shipbuilding and defenses, fleet
missions and combat, espionage reports, and alliances. It doesn't include
purchased resources, speedups, or other gameplay advantages.

## Improvements in this release

- Resource counts and other game quantities round down to whole numbers. The
  interface should show you what you actually have, rather than round a fraction
  up into something you can't spend.
- The game explains its early beta status and links to player policies.
- A **What's new** link opens release notes and change history bundled with the
  installed build. Those pages work independently of our website.
- Running installations provide a download of their source and license notices.

## Running your own universe

Release assets include a complete source archive, a Linux amd64 container image,
and checksums. The container is distributed as a compressed Docker archive:

```sh
gh release download v0.1.0 --repo unbought-games/orbit-imperium
sha256sum -c SHA256SUMS
gzip -dc orbit-imperium-v0.1.0-linux-amd64.tar.gz | docker load
```

The loaded image is `orbit-imperium:0.1.0`. Read the
[deployment documentation](https://github.com/unbought-games/orbit-imperium/blob/v0.1.0/docs/architecture/deployment.md)
for database, configuration, and universe initialization requirements. For a
source checkout, start with the
[README](https://github.com/unbought-games/orbit-imperium/blob/v0.1.0/README.md).

Standalone installations use local authentication. OpenID Connect integration is
available for operators who want it; Unbought Accounts is not required. Operators
are responsible for their server's backups, access rules, and availability.

## Known limitations

This is an early version, not the complete game. The full moon and colonization
systems and several advanced mechanics are not yet available. The official beta
may reset its universe before the full public launch; independent operators make
their own decisions about their servers.

This is the first numbered release, so there is no earlier numbered version to
upgrade from. If you've been running a development build, compare its revision
with this release and back up your database before changing versions.

The official server may run newer changes than this release. Its live updates are
listed separately from numbered release announcements.
