---
id: simulator-ship-fill
title: Add all available ships of one type to a simulation
date: '2026-11-28'
---

Tap the arrow or the available count under a ship’s name in the combat simulator
to fill that ship’s Start field. You can still edit the number afterward.

Thanks to [eleven](https://discord.com/channels/1559681008532586586/1560363739818098738/1575601430813876325)
for suggesting the Dispatch arrow.
