title: Clearer combat planning
date: '2026-11-13'
---

The combat simulator now puts outcomes, surviving cargo, loot, and generated
debris first. It shows average battle rounds, moon-creation chance, and an
estimated recycler count using your universe's rules. Existing debris stays
separate, and moon chance is conditional when the target's moon eligibility is
unknown.

Attacker and defender inputs are grouped by military and civil ships, nonzero
counts stand out, and the Run
button stays within reach. Defender ships and defenses imported from a report
start collapsed with editable summaries. Manual setup remains open, hypothetical
fleets still work, and ship ordering is shared with Fleets and the Shipyard.
You can unlink an espionage report while keeping your entered fleets. Report-based
attack planning opens on demand and uses the same speed controls as Dispatch.
