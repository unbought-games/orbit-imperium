The homepage now introduces Orbit Imperium by name and answers common questions
about free play, getting started, mobile browsers, offline activity, and the
current game. It distinguishes planned universe features from what is playable
today and links to the official game while preserving independent hosting.

The hero keeps its artwork and headline, with a clearer secondary sign-in action
and a directional link to the universe section. Gameplay choices sit beside the
desktop preview, community links share a consistent treatment, and GitHub destinations use the same component. The footer uses the approved motto.

Seasonal Universes and permanent account rewards are described as current,
without a fixed season duration. Final campaigns and Eternal Universes retain
their development status. Answers use native disclosures and appear in initial
HTML, including when JavaScript is disabled.

The page leads with “Play free,” with beta status kept to one small note. Fresh
current-interface screenshots replace the older gallery, without visible
captions. News, alliance, GitHub and Discord links use matching navigation rows.
The scroll cue and hover transitions animate on the landing page while respecting
reduced motion; the in-game immediate-state policy remains unchanged.
