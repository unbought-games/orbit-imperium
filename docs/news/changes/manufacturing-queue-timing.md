title: Clearer timing for ship and defense orders
date: '2026-11-23'

The production bar now resets as each new unit begins and fills forward from
there. While you're drafting an order, the completion estimate includes its
full build time plus any remaining wait in the queue.

Thanks to [Gh0stP1rate](https://discord.com/users/343178308164255744) for
[showing the progress bar running backward between probes](https://discord.com/channels/1559681008532586586/1560363739818098738/1573723352093425748).
