# Ship customization foundation

This development preview introduces an authored Light Fighter with two paint
channels and the empire's current emblem, a full-screen customization hangar,
saved account designs, and independent equipment for each empire. Rendered ship
images are prepared asynchronously and reused across game views.

The new Shipyard and customization UI remain disabled in production builds while
the canonical collection is completed. Empire emblems are isolated between
universes; editing one no longer changes another through a shared template.
