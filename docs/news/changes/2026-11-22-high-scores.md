date: '2026-11-22T09:00:00-05:00'

High Scores now reads each player's score as of their latest completed game
activity. Player and alliance standings share the same exact asset values.
The server records daily standings automatically. If it misses a day, the
page shows movement since the most recent earlier snapshot and displays its date.
