id: command-acceptance-window
title: Recover orders after a lost connection
date: '2026-11-18T00:00:00Z'
---

If a connection drops while you send an order, Orbit can check the original
order after you return. A retry uses the same order for up to 15 minutes.
After that, Orbit refreshes your empire so you can decide what to do next.
An order the server already accepted can still finish on schedule.
