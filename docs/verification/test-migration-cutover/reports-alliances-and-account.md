## What the replacements observe

- **Reports.** The mounted Reports component and real Coordinator receive controlled reads and receipts. It can enter an actual observation from a stretched row, return on acceptance, or leave for report B while report A's archive is pending. In the last case the assertion waits for the authoritative revision caused by A before checking that B remains visible. A refused detail load followed by an abandoned retry waits for the late observation to enter the actual store and checks that the hook sent no mark-read. The public reader has separate document/token and interactive presentation checks. A published public dossier uses recorded identity. An authenticated dossier is checked after the current profile store has actually loaded a conflicting affiliation.
- **Alliances.** The gallery mounts the production AllianceScreen with its own AlliancesController, real Coordinator, memory route, real profile controller and external query/command ports. After the expired cursor it observes both the fresh notice and the live status inside the actual board. Welcome Join retains confirmation, whereas Apply retains its authored draft and input lock. Each uncertain retry sends the original identity and action. A definitive refusal followed by a fresh Apply uses a new identity, and withdrawing clears the application. Separate application journeys own real history, revocation of visible private membership, creation and public publication.
- **Personal invitations and Rewards.** The actual anonymous invitation view owns the sender, return link, CTA position, height and overflow at desktop and phone widths. Authenticated admission recovers from a bound refusal through an explicit retry and actual document replacement. The share form and Rewards page use the real rewards controller with prepared owner results. The selectable clipboard fallback, automatic-title disclosure, safe-default confirmation and visible permanent claim each have a named owner. The mobile account-menu journey consumes an actual claim response. The desktop keyboard entry uses the real account popup. The source-moon transfer retains one real quote, explicit transfer and authoritative reload; both shell widths still exercise containment.
- **Outer-shell limits.** A memory router can show the wrong detail after a stale observer fires, but it cannot validate browser Back, document hydration or pinned-header geometry. The accepted archive history case, authenticated espionage toolbar, both healthy touch-edge cases and their real-shell counterparts remain identifiable in the ledger. Server scope and privacy remain covered by the real storage and HTTP suites.
