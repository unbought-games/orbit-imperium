# README screenshots

The five `readme-*.png` gameplay screenshots were captured November 1, 2026
(2026-11-02 03:03 UTC), from the running game at revision
`0ff75044e6ddf9e1dcbff208ad13b20791f112b8`.

They use an isolated local Rust server and PostgreSQL database with fictional
demonstration accounts, three developed colonies, active queues, a cargo transport,
and neighboring bots. They do not show official-server population or player data.
The frontend was unmodified: no API mocking, generated UI imagery, or retouching.
The images are unchanged copies of the current Unbought Games submission-kit
captures. Canonical capture sources and scenario remain in the studio's brand
workspace; this repository needs no external asset build step.
